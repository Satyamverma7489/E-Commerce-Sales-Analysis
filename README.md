## Project Overview

The E-Commerce Sales Analysis Dashboard is an interactive data analytics project developed using Microsoft Excel. It provides insights into sales performance, profitability, customer payment preferences, monthly sales trends, and regional performance through dynamic charts, KPI cards, and interactive slicers.

## Key Features
- **Total Profit Analysis:** Analyze profit generated across different product categories.
- **Order Tracking:** Monitor the total number of orders.
- **Payment Method Analysis:** Compare Cash, Credit Card, Debit Card, PayPal, and UPI transactions.
- **Monthly Sales Analysis:** Track sales performance across different months.
- **Regional Sales Analysis:** Compare performance across Central, East, North, South, and West regions.
- **Category-Wise Analysis:** Evaluate the performance of products such as Audio, Computers, Electronics, Furniture, Storage, and Accessories.
- **Interactive Filters:** Use slicers to filter the dashboard by payment method, region, category, and month.

## Tools & Technologies
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- Data Visualization
- Sales Data Analysis

## Project Objective
The objective of this project is to transform e-commerce sales data into meaningful visual insights that help users understand business performance, identify sales trends, and compare profitability across product categories and regions.

## Key Outcomes
- Visual representation of sales and profit performance.
- Comparison of regional and monthly sales trends.
- Analysis of customer payment preferences.
- Interactive exploration of business data through filters.

## Conclusion
This project demonstrates the use of Microsoft Excel for data analysis, interactive dashboard creation, and business intelligence reporting.
